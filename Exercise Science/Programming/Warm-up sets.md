> [!summary] Bottom line
> Warm-up sets should potentiate performance without causing fatigue. A few maximal-effort reps or isometric holds in the same exercise or movement pattern as the main set produce post-activation potentiation (PAP), which lasts a few minutes, and post-activation performance enhancement (PAPE), which usually peaks about 6–10 minutes later. Short warm-up sets can't raise muscle temperature much. Keep the reps few so they don't cause fatigue.

## Potentiation vs fatigue

Every bout of exercise has both potentiating and fatiguing effects on the next. Potentiation temporarily raises performance and fatigue temporarily lowers it, and each has several mechanisms. A warm-up meant to maximize workout performance should produce potentiation while avoiding fatigue. There are three main potentiation mechanisms a warm-up can produce: higher muscle temperature, the PAP effect and the PAPE effect.

## Muscle temperature

Sustained low-intensity contractions (15+ minutes) raise muscle temperature, which speeds actin-myosin crossbridge binding and so raises the capacity for fiber tension. Warm-up sets can't realistically do this, because they involve only short periods of contraction.

## Post-activation potentiation (PAP)

PAP is an immediate, temporary increase in the rate of crossbridge binding. When a fiber is activated, the myosin regulatory light chains are phosphorylated, which moves myosin heads closer to actin, so crossbridges form faster and force rises. Classic PAP comes mainly from myosin light chain phosphorylation in type II fibers, boosts force at submaximal levels of activation, and is only significant for a few minutes (usually under 3, with a half-life of about 28 seconds).
[Blazevich 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6838751/)

To produce a big PAP effect, activate as many relevant fibers as possible, which takes a maximal effort. The effort can be dynamic at any speed or isometric, but it should use the same exercise or movement pattern as the main set so the same fibers are activated.

## Post-activation performance enhancement (PAPE)

PAPE is a delayed, temporary rise in voluntary force. In most studies it peaks about 6–10 minutes after the conditioning exercise, when classic PAP has mostly faded, which makes it more relevant for powerlifters than bodybuilders. Its mechanisms are unclear. Changes in muscle temperature, muscle water content and muscle activation may partly explain it, but intense exercise doesn't consistently improve neural drive, and in one study voluntary activation fell after a few maximal knee extensions even as twitch force rose.
[Blazevich 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6838751/)

Because the mechanisms are unclear, so is the best exercise for producing it, but high-effort exercise seems to produce PAPE reliably, much as it produces PAP.

## Programming warm-up sets

To maximize workout performance, program warm-up sets with maximal effort but without fatigue. Options include single dynamic reps with light, moderate or heavy loads, or isometric contractions at the usual sticking point → [[Sticking points in powerlifting]]. The key elements are:
1. use maximal effort,
2. avoid fatigue by not doing too many reps, and
3. use the same exercise or movement pattern as the main set, so the same fibers are used.
