> [!summary] Bottom line
> Variables are measured at one of four levels, which decide what you can do with them. Nominal and ordinal variables are categorical: nominal ones are just labels, and ordinal ones have an order but uneven steps. Interval and ratio variables are numerical with equal steps, but only ratio variables have a true zero, so only they support statements like "twice as much". Sex recorded as male or female is a nominal variable.

## The four levels

Stevens (1946) proposed four levels of measurement, still used in textbooks.

| | Nominal | Ordinal | Interval | Ratio |
|---|---|---|---|---|
| Labels categories | Yes | Yes | Yes | Yes |
| Meaningful order | No | Yes | Yes | Yes |
| Equal differences between values | No | No | Yes | Yes |
| True zero, so ratios hold | No | No | No | Yes |

Nominal and ordinal variables are categorical (qualitative). Interval and ratio variables are numerical (quantitative), and numerical variables can also be discrete (counts, like number of items) or continuous (like height or weight).

- **Nominal:** values have no logical order, so you can only count cases in each category. Examples are sex or gender, brand and educational program. Numbers can be nominal too, like jersey numbers.
- **Ordinal:** values have an order, but the steps between them aren't equal. Examples are agreement scales (disagree, neutral, agree) and the Richter scale, where each step up means 10 times the seismograph amplitude, so the steps aren't equal.
- **Interval:** equal steps between values, but zero is arbitrary, so ratios mean nothing. Celsius is interval: 0 °C still has heat, and 60 °C isn't twice as hot as 30 °C.
- **Ratio:** equal steps and a true zero meaning the absence of the quantity, so ratios hold whatever unit you convert to. Kelvin is ratio: 0 K is absolute zero, and 60 K is twice the thermodynamic temperature of 30 K.

If the difference between consecutive values is always the same, the variable is interval or ratio. Which one depends on whether ratios stay the same when you convert to another scale, which happens only if zero means the absence of the thing measured.
